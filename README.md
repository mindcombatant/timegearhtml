# timegearhtml
Time Gear animation implemented in HTML and CSS, useable as a screensaver in SteamOS. you can also preview it on [my personal website](http://www.mindcombatant.com/timegear/).

## installation on SteamOS (Client Beta)
quick way: copy and run this command in a terminal in Desktop mode:
```
mkdir ~/.local/share/Steam/config/uioverrides/screensavers && cd ~/.local/share/Steam/config/uioverrides/screensavers || cd ~/.local/share/Steam/config/uioverrides/screensavers && git clone https://github.com/mindcombatant/timegearhtml.git "timegear"
```
